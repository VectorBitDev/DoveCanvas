# Dove Canvas

A lightweight game engine built on top of **Raylib-cs**, focused on simplicity, performance, and developer-friendly APIs.

Dove Canvas was created to provide a minimal yet capable foundation for building 2D games without unnecessary complexity. It aims to be easy to understand, quick to extend, and enjoyable to work with.

---

## ✨ Features

- Lightweight and modular architecture
- Built on top of Raylib-cs
- Entity/Component-based world management
- Scene management
- Resource management
- Built-in UI framework
- Audio support
- Camera management
- Integrated profiler
- Debug inspection tools
- System scheduler

## Goals

Dove Canvas is designed with a few core principles:

- Keep the API simple.
- Stay lightweight.
- Make the engine easy to read and modify.
- Favor composition over inheritance.
- Avoid unnecessary abstractions.
